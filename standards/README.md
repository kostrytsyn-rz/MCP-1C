# Стандарты разработки для агента

Папка монтируется в MCP-сервер (`/standards`) и доступна агенту через инструмент
`get_dev_standards(topic)` и MCP-ресурс `standards://...`.

- Каждый `*.md` файл — набор правил. Разделы делятся по заголовкам `##` / `###`.
- `get_dev_standards()` без параметров возвращает оглавление всех файлов.
- `get_dev_standards("запросы")` возвращает разделы, в заголовке или тексте которых встречается тема.
- Правила проекта [1C_DEVELOPMENT_RULES.md](1C_DEVELOPMENT_RULES.md) лежат здесь же и в выдаче идут первыми (путь задаёт `DEV_RULES_PATH`).

Добавьте сюда стандарты своей команды (оформление кода, маркеры изменений, требования к
запросам, БСП и т.п.) — перезапуск сервера не нужен, файлы читаются при каждом вызове.
