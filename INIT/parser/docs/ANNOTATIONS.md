# Поддержка аннотаций расширений 1С

## Что реализовано

Скрипт `merge_config_with_extension.py` теперь поддерживает **интеллектуальное объединение кода** с учетом аннотаций расширений.

## Типы аннотаций

### 1. `&Перед("ИмяПроцедуры")` / `&Before("ProcedureName")`

Код из процедуры расширения **вставляется В НАЧАЛО** оригинальной процедуры.

**Пример - расширение:**
```bsl
&Перед("ПриЗаписи")
Процедура Расш1_ПриЗаписи(Отказ)
    // Дополнительная проверка перед записью
    Если НЕ ПроверитьКонтрагента() Тогда
        Отказ = Истина;
        Возврат;
    КонецЕсли;
КонецПроцедуры
```

**Основная конфигурация:**
```bsl
Процедура ПриЗаписи(Отказ)
    // Основной код записи
    ПроверитьРеквизиты();
    ЗаписатьДанные();
КонецПроцедуры
```

**Результат объединения:**
```bsl
Процедура ПриЗаписи(Отказ)
    // ───────────────────────────────────────────────────────────────
    // РАСШИРЕНИЕ [ut_aa]: &Перед("ПриЗаписи")
    // ───────────────────────────────────────────────────────────────
    // Дополнительная проверка перед записью
    Если НЕ ПроверитьКонтрагента() Тогда
        Отказ = Истина;
        Возврат;
    КонецЕсли;
    // ───────────── КОНЕЦ КОДА ИЗ РАСШИРЕНИЯ [ut_aa] ─────────────
    
    // Основной код записи
    ПроверитьРеквизиты();
    ЗаписатьДанные();
КонецПроцедуры
```

> 📌 **Примечание:** `[ut_aa]` - это название папки с расширением, которое автоматически добавляется ко всем комментариям.

---

### 2. `&После("ИмяПроцедуры")` / `&After("ProcedureName")`

Код из процедуры расширения **вставляется В КОНЕЦ** оригинальной процедуры (перед `КонецПроцедуры`).

**Пример - расширение:**
```bsl
&После("ПриЗаписи")
Процедура Расш1_ПослеЗаписи(Отказ)
    // Логирование после записи
    ЗаписатьВЛог("Документ записан: " + Ссылка);
    ОтправитьУведомление();
КонецПроцедуры
```

**Основная конфигурация:**
```bsl
Процедура ПриЗаписи(Отказ)
    // Основной код записи
    ПроверитьРеквизиты();
    ЗаписатьДанные();
КонецПроцедуры
```

**Результат объединения:**
```bsl
Процедура ПриЗаписи(Отказ)
    // Основной код записи
    ПроверитьРеквизиты();
    ЗаписатьДанные();
    
    // ───────────────────────────────────────────────────────────────
    // РАСШИРЕНИЕ [ut_aa]: &После("ПриЗаписи")
    // ───────────────────────────────────────────────────────────────
    // Логирование после записи
    ЗаписатьВЛог("Документ записан: " + Ссылка);
    ОтправитьУведомление();
    // ───────────── КОНЕЦ КОДА ИЗ РАСШИРЕНИЯ [ut_aa] ─────────────
КонецПроцедуры
```

### 3. `&Вместо("ИмяПроцедуры")` / `&Instead("ProcedureName")`

Код из процедуры расширения **ПОЛНОСТЬЮ ЗАМЕНЯЕТ** тело оригинальной процедуры (объявление остается).

**Пример - расширение:**
```bsl
&Вместо("РассчитатьСумму")
Функция Расш1_РассчитатьСумму()
    // Новая логика расчета с учетом скидок
    Сумма = 0;
    Для Каждого Строка Из Товары Цикл
        СуммаСоСкидкой = Строка.Количество * Строка.Цена * (1 - Строка.Скидка / 100);
        Сумма = Сумма + СуммаСоСкидкой;
    КонецЦикла;
    Возврат Сумма;
КонецФункции
```

**Основная конфигурация:**
```bsl
Функция РассчитатьСумму()
    // Простой расчет без скидок
    Сумма = 0;
    Для Каждого Строка Из Товары Цикл
        Сумма = Сумма + Строка.Количество * Строка.Цена;
    КонецЦикла;
    Возврат Сумма;
КонецФункции
```

**Результат объединения:**
```bsl
Функция РассчитатьСумму()
    // ═══════════════════════════════════════════════════════════════
    // РАСШИРЕНИЕ [ut_aa]: &Вместо("РассчитатьСумму") - КОД ЗАМЕНЕН
    // ═══════════════════════════════════════════════════════════════
    // Новая логика расчета с учетом скидок
    Сумма = 0;
    Для Каждого Строка Из Товары Цикл
        СуммаСоСкидкой = Строка.Количество * Строка.Цена * (1 - Строка.Скидка / 100);
        Сумма = Сумма + СуммаСоСкидкой;
    КонецЦикла;
    Возврат Сумма;
    // ═══════════════ КОНЕЦ КОДА ИЗ РАСШИРЕНИЯ [ut_aa] ════════════
КонецФункции
```

### 4. `&ИзменениеИКонтроль("ИмяПроцедуры")` / `&ChangeAndValidate("ProcedureName")`

**Точечное изменение кода** с использованием операторов `#Вставка` и `#Удаление`.

**Пример - расширение:**
```bsl
&ИзменениеИКонтроль("ЗаполнитьДокумент")
Процедура ааЗаполнитьДокумент(ДокументОснование)
    
    Запрос = Новый Запрос("ВЫБРАТЬ * ИЗ ...");
    Реквизиты = Запрос.Выполнить().Выбрать();
    Реквизиты.Следующий();
    
    #Вставка  //dm240822 - добавлена проверка статуса
    Если Реквизиты.Статус = Перечисления.Статусы.НеСогласован Тогда
        СтатусДляПроверки = Перечисления.Статусы.КОбеспечению;
    Иначе
        СтатусДляПроверки = Реквизиты.Статус;
    КонецЕсли;
    
    ПроверитьВозможностьВвода(
        ДокументОснование,
        СтатусДляПроверки,
        Реквизиты.Проведен);
    #КонецВставки
    
    #Удаление  // Удаляем старый вызов
    ПроверитьВозможностьВвода(
        ДокументОснование,
        Реквизиты.Статус,
        Реквизиты.Проведен);
    #КонецУдаления
    
КонецПроцедуры
```

**Результат объединения (процедура ПОЛНОСТЬЮ из расширения!):**
```bsl

// ═══════════════════════════════════════════════════════════════
// РАСШИРЕНИЕ [ut_aa]: &ИзменениеИКонтроль("ЗаполнитьДокумент")
// Процедура полностью из расширения с обработкой операторов
// #Вставка/#Удаление
// ═══════════════════════════════════════════════════════════════

Процедура ааЗаполнитьДокумент(ДокументОснование)  ← имя из расширения!
    
    Запрос = Новый Запрос("ВЫБРАТЬ * ИЗ ...");
    Реквизиты = Запрос.Выполнить().Выбрать();
    Реквизиты.Следующий();
    
    // ─── ДОБАВЛЕНО В РАСШИРЕНИИ [ut_aa] ───
    Если Реквизиты.Статус = Перечисления.Статусы.НеСогласован Тогда
        СтатусДляПроверки = Перечисления.Статусы.КОбеспечению;
    Иначе
        СтатусДляПроверки = Реквизиты.Статус;
    КонецЕсли;
    
    ПроверитьВозможностьВвода(
        ДокументОснование,
        СтатусДляПроверки,
        Реквизиты.Проведен);
    // ─── КОНЕЦ ДОБАВЛЕНИЯ [ut_aa] ───
    
    // ═══ ЗАКОММЕНТИРОВАНО В РАСШИРЕНИИ [ut_aa] ═══
    //ПроверитьВозможностьВвода(
    //    ДокументОснование,
    //    Реквизиты.Статус,
    //    Реквизиты.Проведен);
    // ═══ КОНЕЦ ЗАКОММЕНТИРОВАННОГО КОДА [ut_aa] ═══
    
КонецПроцедуры
```

**Операторы и их обработка:**
- `#Вставка` / `#КонецВставки` - убираются, код сохраняется с комментарием "ДОБАВЛЕНО"
- `#Удаление` / `#КонецУдаления` - убираются, код **закомментируется** `//` с маркером "ЗАКОММЕНТИРОВАНО"
- English: `#Insertion` / `#EndInsertion`, `#Deletion` / `#EndDeletion`

**Важно:** Берется **полностью процедура из расширения** (включая имя!)

## Процедуры без аннотаций

Процедуры из расширения **без аннотаций** добавляются **в конец** файла:

```bsl
================================================================================
// ДОБАВЛЕНО ИЗ РАСШИРЕНИЯ [ut_aa] (процедуры без аннотаций)
================================================================================

Процедура НоваяПроцедураИзРасширения()
    // Код новой процедуры
КонецПроцедуры
```

## Предупреждения

Если целевая процедура не найдена в основной конфигурации:

```bsl
// ⚠️ ВНИМАНИЕ [ut_aa]: Целевая процедура 'НесуществующаяПроцедура' не найдена
&Перед("НесуществующаяПроцедура")
Процедура Расш1_Проверка()
    // Код процедуры
КонецПроцедуры
```

## Технические детали

1. **Парсер** (`parse_1c_conf.py`):
   - Распознает аннотации на строке перед объявлением процедуры в коде BSL
   - Извлекает события с `callType` из XML файлов:
     - Для **модулей форм**: `Forms/ИмяФормы/Ext/Form.xml`
     - Для **модулей объектов и менеджера**: корневой XML объекта (например, `Documents/ИмяОбъекта.xml`)
   - Сохраняет `annotation_type` и `annotation_target` в метаданных процедуры

2. **Объединение** (`merge_config_with_extension.py`):
   - Метод `_merge_module_files` применяет аннотации при слиянии
   - Использует методы `_insert_before_procedure`, `_insert_after_procedure`, `_replace_procedure`
   - Для `&ИзменениеИКонтроль` используется метод `_apply_change_and_control`
   - **Кэширование:** Если конфигурации уже распарсены, парсинг не повторяется

3. **Поддерживаемые языки и аннотации**:
   - Русский: `&Перед`, `&После`, `&Вместо`, `&ИзменениеИКонтроль`
   - English: `&Before`, `&After`, `&Instead`, `&ChangeAndValidate`
   
   > **`&ИзменениеИКонтроль`** - полностью реализована!
   > - Берет **полностью процедуру из расширения** (включая имя!)
   > - Обрабатывает операторы:
   >   - `#Вставка` / `#КонецВставки` - убирает операторы, код остается с комментарием
   >   - `#Удаление` / `#КонецУдаления` - убирает операторы, код **закомментируется** `//`

4. **Имена расширений:**
   - Имя расширения берется из названия папки (например, `ut_aa`)
   - Автоматически добавляется во все комментарии при вставке кода

---

## Пример запуска

```bash
python merge_config_with_extension.py in_conf/conf_ut/ut in_conf/conf_ut/ut_aa out_conf/conf_ut_merged
```

**Результат:**
```
out_conf/conf_ut_merged/
├── ut/              (основная конфигурация + ut.zip)
├── ut_aa/           (расширение + ut_aa.zip)
└── merged/          (интеллектуально объединенный код + merged.zip)
```
