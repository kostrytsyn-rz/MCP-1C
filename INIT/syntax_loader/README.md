# Syntax Loader — парсер и загрузчик синтаксиса 1С

CLI-инструменты для парсинга документации 1С и Streamlit UI для загрузки готового JSON в Qdrant (HBK/HTML → JSON → Qdrant).

## Рабочий процесс

**Рекомендуемый подход:** CLI для парсинга → UI для загрузки готового JSON

1. **CLI:** Распаковка `.hbk` и парсинг через `parse_structure.py` → создание `structure.json`
2. **UI:** Загрузка готового `structure.json` в Qdrant через веб-интерфейс

Этот подход даёт лучший контроль, повторяемость результата и позволяет переиспользовать готовый JSON.

## Шаг 1: Парсинг через CLI

### 1.1. Распаковка `.hbk` файла (Windows)

Синтакс-помощник хранится в файле **`shcntx_ru.hbk`** (~40 MB) в папке `bin` платформы.
`1cv8_ru.hbk` — это справка по самой платформе, синтакс-помощника в нём нет.

Распакуйте его 7-Zip:

```bash
7z x "E:\Programs\1C\1cv8\8.3.27.2214\bin\shcntx_ru.hbk" -oE:\temp\syntax_extracted -y -mmt=on -bso0 -bsp0 -bb0
```

Если 7-Zip не установлен, можно распаковать в контейнере syntax-loader (в образе есть `p7zip`):

```bash
docker run --rm -v "E:/Programs/1C/1cv8/8.3.27.2214/bin:/hbk:ro" -v "./data/syntax:/out" mcp1cserver-syntax-loader 7z x /hbk/shcntx_ru.hbk -o/out/shcntx -y
```

**Где:**
- Первый аргумент — путь к файлу `shcntx_ru.hbk` (замените версию платформы на свою)
- `-oE:\temp\syntax_extracted` — папка для распаковки
- `-mmt=on` — многопоточная распаковка
- `-y` — автоматическое подтверждение
- `-bso0 -bsp0 -bb0` — тихий режим (без вывода)

Сообщение 7-Zip `Headers Error` для .hbk можно игнорировать, если в результате есть папка `objects/`.

**Результат:** В папке распаковки должен быть подкаталог с папками `objects/` и `tables/`.

### 1.2. Построение структуры (JSON) через CLI

```bash
cd syntax_loader
python parse_structure.py "E:\temp\syntax_extracted" --output "E:\temp\structure.json"
```

**Где:**
- Первый аргумент — путь к корню распаковки (где находится папка `objects/`)
- `--output` — путь для сохранения `structure.json`

**Результат:** Скрипт выведет статистику и создаст файл `structure.json` с полной структурой синтаксиса 1С.

**Примечание:** Если в папке `syntax_loader/` уже есть готовый файл `structure.json`, вы можете пропустить шаги 1.1 и 1.2 и сразу перейти к загрузке через UI (Шаг 2).

### 1.3. Выгрузка в Markdown (опционально)

Синтакс-помощник можно выгрузить в Markdown — один файл на объект платформы (описание, свойства,
методы с синтаксисом, параметрами и примерами) и индекс `README.md`:

```bash
# Из готового structure.json (без .hbk)
python syntax_loader/export_md.py syntax_loader/structure.json --output syntax_md

# Или сразу при парсинге .hbk
python syntax_loader/parse_structure.py "E:\temp\syntax_extracted" --output structure.json --markdown syntax_md
```

Папку `syntax_md/` можно положить в проект, чтобы агент читал документацию напрямую.

## Шаг 2: Загрузка готового JSON через UI

1. Запустите инфраструктуру (если требуется):
```bash
docker-compose up -d
```

2. Откройте UI: http://localhost:8502

3. В разделе "Загрузка файла":
   - Выберите готовый `structure.json` (созданный на шаге 1.2)
   - Нажмите "🚀 Начать загрузку"

4. Дождитесь завершения индексации. UI покажет статистику по загруженным элементам.

**Примечание:** UI настроен для работы с готовым `structure.json`. Парсинг выполняется через CLI для лучшего контроля процесса.

## Что индексируется

- **Глобальные функции** (например: СтрДлина, Формат, ТекущаяДата)
- **Методы объектов** (например: ТаблицаЗначений.Добавить, Запрос.Выполнить)
- **Свойства объектов** (например: ТаблицаЗначений.Колонки)
- Описание, параметры, синтаксис и примеры (если присутствуют в источнике)

Ожидаемые порядки величин (могут отличаться по версии HBK):
- Глобальные функции: ~350
- Методы объектов: ~1 000–7 000
- Свойства объектов: ~1 000–10 000

## Конфигурация

Переменные окружения (или `syntax_loader/config.py`):
- `QDRANT_HOST` — хост Qdrant (по умолчанию: localhost)
- `QDRANT_PORT` — порт Qdrant (по умолчанию: 6333)
- `EMBEDDING_SERVICE_URL` — URL сервиса эмбеддингов
- `COLLECTION_SYNTAX` — имя коллекции (по умолчанию: 1c_syntax_help)
- `BATCH_SIZE` — размер батча при загрузке (по умолчанию: 100)

## Полезные команды

Логи Syntax Loader:
```bash
docker-compose logs -f syntax-loader
```

Остановка UI:
```bash
docker-compose stop syntax-loader
```

Удаление коллекции Qdrant:
```bash
curl -X DELETE "http://localhost:6333/collections/1c_syntax_help"
```
